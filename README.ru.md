# AdPulse 📊

[English](README.md) | **Русский**

> **AdPulse** — современная, автономная, self-hosted web-платформа для автоматической ежедневной доставки отчётов по рекламе **Meta (Facebook & Instagram) Ads** прямо в **Telegram** (личка, группы, темы/topics) и **Google Sheets**.
>
> Полная бесплатная open-source альтернатива SaaS-сервисам автоотчётов без сторонних копирайтов и подвалов «Отправлено через...».

---

## ⚡ Особенности и возможности

- **Производные метрики (CPC, CPM, CTR, цена результата) считаются из суммарных расхода и количеств, а не усредняются по кампаниям; дельты периодов считаются из исходных компонентов.**
  - Все аддитивные метрики суммируются по кампаниям (`spend`, `impressions`, `clicks`, `leads`, `messages`, `calls`...).
  - Коэффициенты эффективности (`CTR`, `CPC`, `CPM`, `CPP`, `CPL`, `Cost per DM`, `ROAS`) рассчитываются из итоговых сумм без усреднения ставок.
  - Дедуплицированный охват (`reach`) запрашивается на уровне рекламного кабинета с фильтрацией по кампаниям.
  - Неподдерживаемые или отсутствующие метрики отображают «н/д» вместо нулей.
- **Сравнение периода к периоду (Period Comparison)**:
  - Автоматическая отправка отдельного структурированного сообщения в Telegram с динамикой «было → стало», разбитой по блокам («Общие», «Эффективность», «Конверсии и стоимость»).
  - Полярные индикаторы дельты (зелёный при росте конверсий или снижении стоимости, красный при падении результатов, нейтральный для расхода и показов).
  - Математическое правило округления: `.5` округляется в сторону от нуля (`−12.5% → −13%`, `+12.5% → +13%`), для малых дельт менее 1% выводится один знак (`+0.3%`, `−0.5%`), а `= 0%` выводится строго при абсолютном равенстве.
  - Строки, где метрика отсутствует в обоих периодах, автоматически скрываются из сообщения.
- **Хранение снимков и защита от дублей**:
  - Сырые ответы Meta API сохраняются в `raw_meta_snapshot` с меткой времени `fetched_at` и режимом атрибуции, автоматически очищаясь воркером старше 90 дней с сохранением всех числовых метрик и ID сообщений.
  - Защита от гонок и дублей на уровне частичного уникального индекса PostgreSQL для статусов `sending`, `success`, `no_data`.
- **Буфер ожидания финальных данных (Final Data Delay)**:
  - Meta пересчитывает атрибуцию конверсий в течение нескольких часов после окончания суток. AdPulse выдерживает настраиваемый буфер (по умолчанию 6 часов) после завершения отчётного периода в часовом поясе кабинета, прежде чем отправлять отчёт.
- **5-шаговый мастер создания отчётов (Wizard)**:
  1. **Платформа и назначение**: Meta Ads + выбор каналов (Telegram и/или Google Sheets).
  2. **Кампании**: выбор аккаунта, режим кампаний (все / фильтрованные по целям и названиям / конкретный список).
  3. **Метрики**: 4 готовых шаблона («Ежедневный пульс», «Лидогенерация», «Личные сообщения», «Узнаваемость»), сетка из 24 метрик с подсказками, умное определение, кастомизация названий и живой предпросмотр сообщения Telegram в реальном времени.
  4. **Расписание**: периодичность (ежедневно, еженедельно, ежемесячно), время отправки и часовой пояс пользователя с учётом часового пояса кабинета.
  5. **Подключение**: привязка Telegram бота (в личку по deep-link или в группу/канал/тему через `/link <код>`), привязка Google Sheets с автосозданием шапки и проверкой прав, кнопка «Тестовый отчёт» для мгновенной проверки.
- **Многопользовательская безопасность**:
  - Регистрация и вход с хешированием Argon2id, rate limiting для защиты от брутфорса.
  - Строгая изоляция данных: все сущности жёстко привязаны к `user_id`.
  - Шифрование токенов Meta алгоритмом AES-128/256 (Fernet) в базе данных. Токены никогда не логируются и не отправляются на фронтенд.
  - Функция «Удалить мой аккаунт и все данные» с каскадным удалением.
- **Интернационализация (i18n)**:
  - Русский (по умолчанию), O'zbekcha, English.
  - Тёмная тема по умолчанию с возможностью переключения на светлую.
  - Фирменный шрифт JetBrains Mono.

## 🛠 Стек технологий

- **Backend**: Python 3.12, FastAPI, SQLAlchemy 2.0 (async), Alembic, PostgreSQL 16.
- **Worker / Scheduler**: Фоновый сервис с персистентным планировщиком в БД, исключающий дублирование и потерю запусков при перезагрузках контейнера.
- **Telegram Bot**: `aiogram 3` (long-polling по умолчанию, опциональный webhook).
- **Google Sheets**: Google API Client v4 с сервисным аккаунтом.
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide icons.
- **Развёртывание**: Docker Compose (сервисы `api`, `worker`, `db`, `web`).

## 🚀 Быстрый старт (One-command Deploy)

Требования: Docker и Docker Compose (любой Linux / Debian VM, 2 vCPU, 4–8 GB RAM).

```bash
# 1. Склонируйте репозиторий
git clone https://github.com/Gob7912/Adpulse.git adpulse
cd adpulse

# 2. Скопируйте и настройте переменные окружения
cp .env.example .env

# 3. Запустите стек контейнеров
docker compose up -d --build
```

После запуска сервис будет доступен:
- **Веб-интерфейс**: `http://<your-server-ip>/` (порт 80)
- **API Документация (Swagger)**: `http://<your-server-ip>/api/docs`

## 🔑 Инструкции по настройке интеграций

### 1. Как создать Telegram бота (@BotFather)
1. В Telegram откройте диалог с [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте подсказкам:
   - Введите отображаемое имя (например, `AdPulse Reporter`).
   - Введите юзернейм бота, заканчивающийся на `bot` (например, `MyCompanyAdPulseBot`).
3. Скопируйте полученный HTTP API токен.
4. Откройте файл `.env` и укажите:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
   TELEGRAM_BOT_USERNAME=MyCompanyAdPulseBot
   ```
5. *(Рекомендуется)* В `@BotFather` включите поддержку групп: `/setprivacy` → выберите вашего бота → `Disable` (чтобы бот видел команду `/link` в группах).

### 2. Как настроить Google Sheets (Сервисный аккаунт)
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект (например, `adpulse-reports`).
3. В разделе **APIs & Services → Library** найдите и включите **Google Sheets API**.
4. В разделе **IAM & Admin → Service Accounts** нажмите **Create Service Account**.
5. Нажмите на созданный сервисный аккаунт → вкладка **Keys** → **Add Key** → **Create new key** (JSON). Файл ключа скачается на ваш компьютер.
6. В файле `.env` укажите email сервисного аккаунта и содержимое JSON-файла:
   ```env
   GOOGLE_SERVICE_ACCOUNT_EMAIL=adpulse-service@adpulse-reports.iam.gserviceaccount.com
   GOOGLE_SERVICE_ACCOUNT_JSON='{"type": "service_account", ...}'
   ```
7. При создании отчёта в шаге 5 поделитесь вашей Google Таблицей с указанным email с правами **«Редактор» (Editor)**.

### 3. Как получить токен Meta Ads (System User Token)
1. Откройте [Настройки компании Meta](https://business.facebook.com/settings).
2. Перейдите в раздел **«Пользователи» → «Системные пользователи»** (System Users) и нажмите **«Добавить»**.
3. Задайте имя (например, `AdPulse System`) и выберите роль **Администратор**.
4. Нажмите **«Назначить объекты»** (Assign Assets), выберите ваш **Рекламный аккаунт** и включите разрешение **«Управление кампаниями»** или **«Просмотр эффективности (ads_read)»**.
5. Нажмите **«Сгенерировать новый маркер»** (Generate New Token):
   - Выберите ваше Meta App.
   - Срок действия: **«Никогда» (Never)**.
   - Обязательно отметьте разрешение: `ads_read`.
6. Скопируйте сгенерированный токен и вставьте в AdPulse при создании отчёта.

## 🧪 Запуск тестов и линтера

Боевые образы `api` и `worker` ставят только необходимые для работы зависимости из `requirements.txt`. Инструменты разработки и тестирования (`aiosqlite`, `ruff` и др.) вынесены в `backend/requirements-dev.txt`.

### Локальный запуск:

```bash
cd backend
source venv/bin/activate
pip install -r requirements-dev.txt
PYTHONPATH=. pytest -v
ruff check .
```

### Запуск через Docker:

```bash
docker compose run --rm -v "$(pwd)/backend":/app -w /app api sh -c "pip install -r requirements-dev.txt && PYTHONPATH=. pytest -v && ruff check ."
```

Автоматические тесты покрывают:
- Строгий расчёт соотношений без усреднения (CTR, CPC, CPM, CPP, CPL, Cost per DM, ROAS).
- Защиту от деления на ноль при пустых кампаниях.
- Задержку финальных данных (Final data delay 6h) с учётом часовых поясов.
- Эталонные замороженные фикстуры и проверку соответствия данным Ads Manager.
- Защиту от дублей и конкурентных запусков через частичный индекс PostgreSQL.
- Форматирование дельт меньше 1%, округление `.5` от нуля и строгое равенство `= 0%`.
- Пагинацию и обработку ошибок Meta API (Error 190 / Token Expired).
- Генерацию HTML-сообщений для Telegram и форматирование строк Google Sheets.
- Изоляцию пользователей и полный цикл мастера создания отчётов.
- Краевые случаи редактирования отчётов, смену аккаунтов и сохранение привязок Telegram.
